# Anvelos Softwares Milestones

Welcome to the Anvelos Softwares Milestones repository. This project is a Next.js application that showcases the progression of our UI/UX milestones, ending with a premium administrative dashboard.

## Overview

This application serves as a central hub (landing page) that links to various stages (milestones) of our project's frontend development.

- **Milestone 1:** Initial Landing Page concepts and structure.
- **Milestone 2:** Admin Dashboard UI built with Tailwind CSS.
- **Milestone 3:** Final polished UI components.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (Utility-first approach)
- **Icons:** Lucide React
- **Features:** Dark mode support, Responsive design, Modern premium aesthetics.

## Getting Started

First, make sure you have installed all dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The root URL automatically redirects to `/landing`.

## Deployment

This project is optimized for deployment on [Vercel](https://vercel.com/). You can easily deploy it by connecting your GitHub repository to Vercel.
